# King's Bird 复刻关卡制作 Skill(逐帧描摹长关管线)

> 适用对象:当前游戏内 **第 1 关「金绿森林」**(原视频 19–22s,数据槽位 SEGS[3])与
> **第 2 关「青蓝水城」**(原视频 23–31s,数据槽位 SEGS[4])。
> 第 3 关「笼中蓝城」为程序生成,不走本管线。
> 工具链:`tmp/stitch_kb2.py`(描摹+拼接)→ `tmp/emit_trace2.py`(注入)→ `scripts/main_kingsbird.lua`(运行时)。

---

## 一、管线总览(四步)

```
原视频片段
  │ ① 选帧        ffmpeg 每 0.5~0.8s 抽 1 帧(st<N>_<t>.png, 裁掉顶部 40px UI)
  ▼
  │ ② 分层描摹    每帧像素 → 按"层色表"归类 → 各层轮廓多边形(OpenCV)
  ▼
  │ ③ 位移+拼布   帧间镜头位移(边缘图模板匹配)→ 世界空间逐层"仅新增区域"拼贴 → 全层重新描摹
  ▼
  │ ④ 注入运行时  多边形+包围盒写入 Lua;最暗层=碰撞体;其余层按视差渲染
```

核心思想:**画面与碰撞同源**——不手摆任何几何,前景碰撞体就是原帧前景色块的轮廓。

## 二、层色表设计(前后景的灵魂)

每关定义一张 `(RGB, parallax, collide)` 层表,按 **远 → 近** 排序(后画的盖前画的)。
RGB 必须来自对原帧的 kmeans 聚类(K=8),**不许手拍颜色**。

### 设计规则

1. **视差赋值按明度排**:越亮越远(0.1~0.35),中间调 0.45~0.7,最暗 1.0。
2. **碰撞层 = 视差 1.0 的最暗 1~2 层**,且**前景层全部参与碰撞**——
   原作里的黑柱就是要蹬墙绕越的实体。⚠️ 不要再加"贯穿全屏=背景柱豁免"类规则,
   在拼接画布上会把整个前景误杀(踩过的坑)。
3. 一个颜色簇若兼任"前景+背景"(如森林的近黑绿既是平台又是远树干),宁可全给碰撞;
   玩法上"多一面可蹬的墙"远好于"踩空"。
4. **亮度 >235 的像素全局剔除**(玩家拖尾/角色/获奖水印),否则会烘焙成假地形。
   已知残留:角色**暗色**剪影偶尔逃过过滤变成"假人雕像",可按人形尺寸孤块二次清理。

## 三、帧间位移与拼布(长关成形)

- **位移估计**:前景掩码 → Canny 边缘 → 0.25× 粗扫 `matchTemplate(TM_CCOEFF_NORMED)`
  → 全分辨率 ±26px 精修。**符号约定必须用 np.roll 合成数据自检**(`selftest passed` 才可信)。
  - 纯掩码相关/相位相关在大面积平涂画面上不可靠,勿回退。
  - 画面上的静态水印(获奖标)会污染特征匹配,边缘图法也要靠置信度门槛挡。
- **置信门槛**:conf>0.30 且 |dx|<1300、|dy|<600;可疑负移需 conf≥0.40。
  不达标 → 改用**固定右进步长 680**(平台跳跃片段整体右进的先验),保住关卡推进。
- **拼布(关键)**:逐层世界画布,**每帧只把"未被先前帧覆盖的区域"贴进画布**,
  然后对整张画布统一描摹一次 → 同一世界区域只来自一帧,机制上杜绝错位重影。
- 输出:`kb_trace2.json` + `pano2_<N>.png` 前景全景(带世界坐标网格,**点位标定全靠它**)。

## 四、玩法点位(spawn / 存档点 / 终点)

在 `tmp/emit_trace2.py` 的 `CONF` 表里配置,坐标系 = 拼接世界坐标(看 pano2 网格读数):

| 关 | spawn | 存档点 | goal | kill |
|----|-------|--------|------|------|
| 森林 | (450,940) 长横梁 | (2200,700) 高梁 / (3500,975) 右梁 | (4250,1230) | 1750 |
| 水城 | (80,550) 左岸 | (2780,260) 斜塔顶 / (5716,560) 终塔 | (5716,500) | 1500 |

**两层保险(运行时自动,标点可以糙)**:
1. 加载时 spawn/存档点**垂直吸附到下方最近"顶面"**(交点下方 5px 必须在实体内,防吸到平台底面);
   吸附结果不回写关卡数据(防多次进关越沉越深——踩过的坑)。
2. **坏档自愈**:回档后未落地连摔 2 次 → 自动退回关卡起点。

## 五、运行时要点(main_kingsbird.lua)

- **渲染**:`drawTraceLayers()` 按层序填多边形;层偏移 = `(cam - ref) * (1 - par)`
  (ref = 首帧中心 840,455;垂直方向再 ×0.5);**逐多边形包围盒裁视口**(长关必须,否则掉帧)。
  天空 = 帧底色平涂。`LV.ZOOM = 0.92`。
- **碰撞**:圆 vs 多边形边链 + 包围盒剔除;**射线法内部检测**,卡入实体时向最近边外侧弹出
  (推出方向若按"最近点→玩家"算,在体内是反的——踩过的坑);
  子步 = `ceil(速度/5.5)` 防穿入;卡死 30 帧自动回档。
- **运动**:水墨游戏口径(accel 1.6 / fric 0.86 / grav 0.52 / jump 15.5 / J 八向冲刺 19×12f /
  蹬墙跳 ±9.5,-13 / coyote 6)。
- **拖尾**:拉格朗日流体墨尾(基宽 34;J 触发后**锁存冲刺形态 46 帧**让液化撕裂完整演完;
  necking 2.4→3.8;飞白阈 0.35;断口喷溅 0.26 概率反向拉丝)。
- 按键:A/D 跑、SPACE 跳、J 冲刺、R 回档、Q/E 切关、1-3 直跳。

## 六、新做一关的操作清单

1. 选片段,抽帧:`ffmpeg -ss <t> -i 录屏.mp4 -frames:v 1 tmp/vid/st<N>_<t>.png`(0.5~0.8s 一帧)
2. 对代表帧跑 kmeans(K=8)拿主色 → 在 `stitch_kb2.py::SEGS` 写层表(远→近,视差按明度)
3. `python tmp/stitch_kb2.py` → 看 `pano2_<N>.png`:
   - 全景破碎/重影 → 检查位移日志里 STRIDE 比例,必要时加密抽帧
   - 前景近乎消失 → 检查碰撞层是否被误过滤
4. 按 pano2 网格在 `emit_trace2.py::CONF` 标 spawn/cps/goal/kill(糙一点没关系,有吸附兜底)
5. `python tmp/emit_trace2.py` 注入 → `tools/run_kingsbird.ps1` 起游戏
6. 验收:控制台 `respawn at` 计数为 0(空载 15s);实玩检查穿模/断路

## 七、踩坑备忘(违者重蹈)

- OpenCV 在中文路径下必须 `imdecode/imencode`(imread 静默失败)
- git-bash 长 heredoc 必破 → patch 一律写 `tmp/*.py` 再执行
- 位移符号、形态学参数等"感觉对"的代码 → 先合成数据自检再上真数据
- 任何按"单帧尺度"设计的启发式(高度阈值、面积阈值),挪到拼接画布上前必须重新推导
