# 《墨境行》游戏策划案

> 版本 v1.0(2026-06-12)。本案是项目唯一的设计权威文档,与
> `docs/movement_spec.md`(运动学数表)互为引用;冲突时以本案的设计意图为准、
> 以 movement_spec 的数值为准。

---

## 一、游戏概述

| 项 | 内容 |
|---|---|
| 名称(暂) | 墨境行(系列卷名:水墨平台跳跃) |
| 类型 | 2D 横版平台跳跃(架构上重构为"本质 3D 的 2D 横视角",即 Unity 式 2.5D) |
| 引擎 | UrhoX(Urho3D 系),Lua 5.4,NanoVG / CustomGeometry |
| 单局结构 | 关卡制,每关一幅独立水墨手卷,单关 2~4 分钟 |
| 核心幻想 | **玩家是一滴有灵的墨**,行走在一幅未完成的画里;走过之处,画被补完 |
| 核心循环 | 观察残卷 → 规划路线 → 平台机动 → J 点墨补笔(交互)→ 路被画出 → 抵达卷尾 → 画卷装裱钤印 |
| 情感目标 | "我完成了这幅画"的成就感;水墨的静气 + 平台跳跃的爽利,两者不打架 |

## 二、美学设计(美术圣经)

### 2.1 总纲

每一关是**一幅横向长卷**。开卷时它是"未完成的画稿";玩家通关的过程就是作画的过程;
终幕镜头拉远,整卷铺开、装裱、题跋、钤印——**关卡结算 = 画作完成**。

### 2.2 纸与墨

- **纸**:宣纸底色系(基准 RGB 243,239,229,各关可微调冷暖)。纸即虚空、即天空、即雾。
- **三墨规则(铁律,兼任玩法可读性)**:
  - **浓墨**(约 30,28,26):实体。**凡浓墨皆可踏**,凡可踏皆浓墨。
  - **中墨**(约 104,100,90):前中景的景物笔触,不可交互。
  - **淡墨**(约 152,148,138):远景。
- **留白即空间**:空白不是"没画",是构图的一部分。"疏可走马,密不透风"——
  大面积留白必须被两侧的密笔触框出来才成立。
- **笔法词汇表**(实现时的视觉语言):飞白(枯笔扫出的引导暗示)、皴(石的质感笔)、
  苔点(点苔,可兼任路径暗示)、没骨(花瓣直接以色块成形)、个字/介字(竹叶组的布叶法)。

### 2.3 构图法则(每关地形必须满足)

1. **丛而非杆**:同类元素成组出现(两三竿一丛),组内穿插交错、高低粗细参差;组间大段留白。
2. **主从呼应**:全卷有且只有一处"主笔"(最重的视觉锚点),其余皆为从。
3. **势与破**:全卷笔触有统一的倾向(顺行进方向微倾),并安排至少一处反向的"破"打破单调。
4. **密度曲线**:卷首密 → 疏 → 中 → 密(主笔/高潮)→ 疏 → 卷尾密,首尾呼应;
   密度曲线必须与玩法节奏(教学-挑战-喘息-高潮-收尾)同相。
5. **无根之物不入画**:一切竖立元素必须从石、坡、或画外边沿长出。

### 2.4 画题公理(本项目最高设计法则)

> **地形即画题,交互即补笔。**

- 玩家踩的东西必须本身是画元素(竹竿、梅枝、山石、屋檐……),不允许抽象色块平台。
- 交互的产物必须是该画元素**天然会生长的东西**:竹生叶、梅开花、石生苔、水起涟。
- 交互点的位置必须**长在结构上**(叶在竿头、花在枝梢),严禁悬空乱撒。
- 一关只取**一个画题**(如 18 关纯竹),一关只说透**一个交互动词**。

### 2.5 色彩纪律

- 基调永远是纸色 + 墨色五阶。
- 每关允许**一个点睛色**(印章朱红 / 梅红 / 鎏金),用量克制,只给最重要的东西
  (印章、终点、关键交互反馈)。
- 禁止渐变彩、禁止饱和色块、禁止西式卡通光影。

### 2.6 动效笔意(反馈语言,全项目统一)

| 名称 | 实现 | 用在哪 |
|---|---|---|
| 顿笔 | 命中瞬间 2~3 帧 hitstop(位置冻结、速度保留) | 一切关键交互命中 |
| 墨绽 | 径向墨屑粒子爆开 | 交互触发、收集 |
| 笔锋动画 | 新生长的枝/叶以一道快速运笔画出,笔走到哪眼睛跟到哪 | 铺路、开花、生长——**生长动画本身就是引导,不允许用 UI 箭头** |
| 镜头随笔锋 | 触发瞬间镜头朝生长方向轻推 20~40px,22 帧衰减 | 配合笔锋动画 |
| 拒绝颤 | 错误方式触碰交互点时,交互点轻颤 2~3 下 | 教玩家"换个动词" |
| 装裱终幕 | 镜头自动变焦铺开全卷 → 装裱框紧贴画心合拢 → 题跋浮现 → 红印带回弹砰盖 | 每关通关结算 |

## 三、角色设计

### 3.1 形态:墨珠

- 一颗**圆滚滚、有流体特性的黑墨珠**,半径 10px(碰撞半径,视觉略大)。
- 动态:落地压扁、起跳拉伸、冲刺时液化收缩成梭形——始终保持"一滴墨"的材质感。
- 无面部、无四肢。它的"表情"全部由形变和拖尾表达。

### 3.2 拖尾(角色的灵魂)

- **黑色拉格朗日流体墨尾**:骨架点世界锚定,张力 0.65/0.93,梯度噪声颈缩,
  飞白碎裂、墨滴甩出;冲刺时收窄液化、急停时回弹。
- 性能纪律:骨架点每帧最多裁 1~2 个(批量裁剪会造成卡顿,已踩过坑)。

### 3.3 运动能力(standard 组,完整数表见 movement_spec §2)

| 能力 | 数值 | 备注 |
|---|---|---|
| 跑速 | 9.83 px/帧(16 帧到 90%) | 短平台 ≥100px 即可重新起步 |
| 跳 | 高 223 / 助跑远 580 / 滞空 59 帧 | **无长按跳高、无二段跳、无土狼时间** |
| J 冲刺 | 8 向,19px/帧 × 12 帧 = 本体 218 | 冲刺中无重力;空中仅一次;落地/蹬墙跳/**命中交互点**时刷新 |
| 跳+冲刺 | 最大平距 787 / 最大总高 789 | 必经路线一律打 8 折 |
| 蹬墙 | 跳高 201 / 横转移 561;贴墙下滑 108px/s | 双柱夹缝间距 120~360 可循环爬 |

## 四、核心机制

### 4.1 触苞补笔(主交互,18+ 关的唯一动词)

- **苞 = 未完之笔**:有苞的结构,末端是"断笔"——无碰撞、不可落脚,
  只有一条飞白虚笔从断口弱弱探出,苞悬在笔锋处呼吸。
- **触发条件:必须处于 J 冲刺状态命中**(半径 80)。
  - 普通跳跃/行走触碰 → 苞轻颤拒绝,不触发。
  - 冲刺命中 → **收笔**:冲刺立即结束、速度收掉(vx 压至 ±2.5、vy 清零),
    墨珠稳落当场展开的叶台上,**永不冲过头**;同时**刷新冲刺**。
- **触发效果(铺路)**:顿笔 → 墨绽 → 笔锋动画依次画出:补完断梢 → 苞处横枝叶台 →
  向前 1~4 级铺路枝叶台,直指下一个落点。**全部永久存在,无计时消失**。

### 4.2 碰撞 = 笔画本体

- 叶台的碰撞体是画出来的**横枝**(枝即站立面),叶簇生在枝上;
  严禁碰撞体超出可见笔画("空气碰撞体"是 P0 级 bug)。
- 地形碰撞与渲染同源生成(同一根贝塞尔竿轴),节缝处碰撞段重叠 +6px 防卡缝。

### 4.3 通行结构

- **存档点**:石上灯/杈台,触达点亮,死亡回最近存档点。
- **跌落**:超出 kill 线即回档(深涧即重开,涧底若可生还必须给苔点等视觉逃生暗示)。
- **终点卷口**:卷尾的收笔环,触达进入装裱终幕,玩家冻结,终幕毕自动进下一关。

### 4.4 软墙(用物理代替空气墙)

- 缺口宽 > 跳+冲刺极限 × 0.95(standard:748px)= 不可逾越,可放心当墙用。
- **滑翔补正(重要,曾出过漏洞)**:带下落的缺口,射程额外 + √(2·落差/重力)×9.83;
  落差 472px 时实测包络可达 ~1206px。**一切跨涧软墙必须按补正后的包络校验**。

## 五、关卡设计规范

### 5.1 设计流程(每关五步,顺序不可乱)

1. **定画题与动词**:这关画什么?交互动词是什么?(一关一题一动词)
2. **构图小样**:按 §2.3 法则排五段式密度曲线,出构图草图(工具脚本出 PNG 例图)。
3. **锚点与间距**:交互点按 §2.4 长在结构上;间距按 §5.2 硬规则表排。
4. **可达性校验**:跑校验脚本,必经段全过、软墙全部成立(含滑翔补正)才算过。
5. **试玩与手感**:上手跑全程,按 §5.3 节奏表核对。

### 5.2 间距硬规则(standard 组;其余参数组按 movement_spec 内插)

| 用途 | 数值 | 说明 |
|---|---|---|
| 必经纯跳缺口 | ≤ 460 | 助跑跳远 × 0.8 |
| 必经上台阶 | ≤ 175 | 跳高 × 0.8 |
| 必经跳+冲缺口 | ≤ 630 | 最大平距 × 0.8 |
| 杈梯/踏点竖距 | ≤ 155 | 留容错 |
| 交互点链(冲刺串联) | 相邻 ≤ 175 | 冲刺本体 × 0.8,命中刷新冲刺 |
| 软墙 | > 748 + 滑翔补正 | 见 §4.4 |
| 挑战/隐藏路线 | ≤ 0.95 系数 | 永不设计 100% 极限必经跳 |

### 5.3 节奏(起承转合)

- **起**:安全区(下方有地),建立画题与动词认知;失误无惩罚。
- **承**:第一次真风险(涧上),动词成为必需。
- **转**:动词的变奏与连段(空中连续命中、节奏压缩),关卡高潮;主笔构图同步出现在这里。
- **合**:动词的收束应用(长下行/护送回地),情绪放缓,接终幕装裱。
- 教学一律放在更早的关卡;18+ 关是正式关,**不做显性教学**。

### 5.4 镜头

- 广角:zoom 0.75~0.92(按关卡纵深定),慢跟随(x 0.07 / y 0.06),世界边缘 clamp。
- 镜头随笔锋(§2.6);终幕自动变焦铺卷,从当前 zoom 平滑插值到 fit 全卷。

## 七、范例关详案:第 18 关《墨竹行》

- **画题**:墨竹长卷(兰竹石传统,只有竹与石)。**动词**:J 点墨 → 补笔铺路。
- **世界**:4750 × 900,kill 1060,zoom 0.82。
- **五段式**:
  1. 卷首·密(0~700):坡石两块 + 可玩竹丛(竿上杈梯)+ 笋;下方有地,安全起步。
  2. 涧·疏(700~1200):纯留白,飞白虚笔探涧;苞① 铺两级台跨涧。
  3. 涧中孤丛(1200~2000):苞②③ 连段;苞间 800~840(超软墙),叶台是唯一的路。
  4. 石竹相依 + 主笔(2300~3200):R1 大石(cp2)→ **风压斜竹长坡**(全卷主笔大斜线,
     踏竿身而上)→ 梢端杈台(cp3)。
  5. 卷尾·密(3500~4750):末苞④ 垂梢四级长下行送回坡石;卷尾竹丛 + 卷口;
     cp3→卷尾涧宽 1270(已含滑翔补正,不可绕)。
- **苞表**:4 苞;每苞:断梢 + 冲刺命中收笔 + 铺路链(2/2/2/4 级)。
- **当前已知问题(P0)**:手感差(待专项打磨:起跳/冲刺窗口/落台反馈);
  构图美化(丛、伴竹、主从、石形重画)尚未实施;伴竹规则已定:可踩、不入涧。

## 八、技术架构与纪律

- **构建**:`tools/build_main.ps1` 按文件名序拼接 `scripts/src/*.lua` → `main.generated.lua`;
  **chunk 顶级 local 已 199/200,新代码一律全局命名**;大数据表必须逐句赋值(寄存器上限)。
- **碰撞**:任意多边形 × 圆(子步推进、内部反弹喷出、速度自适应)。
- **工具链**:`tools/movement_metrics.py`(数表再生)、可达性校验脚本、构图例图脚本、
  PrintWindow 截图(不抢焦点)。
- **2.5D 重构(已立项)**:「纸境」架构三阶段——
  ① 立壳:Scene + 小 FOV 透视相机 + 玩法平面 z=0,18 关试点,物理零改动;
  ② 管线化:nvg 笔触 → 笔触网格工具集,17 关逐关迁;
  ③ 吃红利:中后景 z 层化、镜头语言、CustomGeometry 置景。
  已知坑:gamma ^2.2 预编码、贴图路径 assets/ 前缀、Plane 朝向。
- **音频**:项目当前无音频系统(纯视觉),立项另议。
