# 《墨竹行》实机画面视频生成案

> 用途:供 AI 视频生成 / 宣传片制作使用的单关实机画面描述案。
> 目标:**15 秒**视频,加速展示一个完整游玩约 **3 分钟**的关卡(第 18 关《墨竹行》)。
> 风格基准:本案 §2;分镜与变速曲线:本案 §3(逐秒)。

---

## 1. 一句话概括

一颗黑色墨珠在一幅未完成的水墨竹卷上奔跑跳跃,每次冲刺点中悬空的墨苞,
画面就当场用毛笔笔锋画出新的竹枝竹叶供它落脚;15 秒内以变速蒙太奇走完整卷,
最终镜头拉远,整幅竹卷装裱完成、盖下朱红印章。

## 2. 画面风格规格(全程恒定)

- **画面比例** 16:9,横向卷轴式横移为主。
- **底色**:温润的宣纸米白(RGB 约 243,239,229),带极细的纸纹颗粒;没有天空、没有地平线,
  纸即虚空。
- **墨色五阶**:画面上只有墨——浓墨(近黑,所有可踩的竹竿、坡石)、中墨、淡墨;
  唯一彩色是**朱红印章**(终幕)和存档灯的一点暖黄。
- **画风**:中国写意墨竹(兰竹石传统)。竹竿是弓弯的贝塞尔长竿、节间留白、节痕深墨短弧;
  竹叶是"个字/介字"布叶的柳叶形笔触;石头有皴笔与苔点。**严禁**:3D 光影、彩色渐变、
  西式卡通描边、镜头光晕。
- **主角**:半径约 10px 的**黑墨珠**,圆滚滚有流体感——落地压扁、起跳拉伸、冲刺液化成梭形;
  身后拖一条黑色流体墨尾,高速时墨尾拉长、出现飞白碎裂和甩出的小墨滴。
- **UI**:无任何 UI(纯画面)。
- **加速段的运动处理**:加速不靠运动模糊,靠**墨尾变长 + 帧间距加大**表达速度;
  画面始终干净锐利。

## 3. 分镜脚本(逐秒,总长 15s)

> 速度倍率指"相对实机正常速度"。关键交互瞬间永远回到 1x——
> 慢下来的那一笔才是本片的记忆点。

| 时间 | 倍率 | 画面 | 镜头 |
|---|---|---|---|
| 0.0–1.0s | 1x | 纸白,一支看不见的笔以两道飞白扫出卷首坡石与三竿浓墨竹(快速作画感);墨珠从画外滚入,落在坡石上压扁回弹 | 静止,卷首全景(略广角) |
| 1.0–2.5s | 3x | 墨珠沿第一根竹竿的杈枝"之"字蹬跳而上(杈枝是竿上横出的小枝);竿顶以上是**断笔**——竹梢没画完,只有一条枯笔虚线探向空中一颗悬浮的、缓缓呼吸的墨苞 | 跟随上摇 |
| 2.5–4.0s | **1x(本片第一记忆点)** | 墨珠跃起,空中化作梭形**冲刺**直取墨苞;命中瞬间画面**顿笔定格 2~3 帧**,墨屑爆开;随即一道毛笔笔锋以可见的运笔速度补完断梢、横出一根枝、铺开一簇竹叶——墨珠稳稳落在新画出的叶台上 | 命中瞬间轻微推近,随笔锋方向轻推 |
| 4.0–6.5s | 6x | 涧上连段蒙太奇:墨珠沿刚画出的叶台链连跳,冲刺点中第二、第三颗墨苞,每次命中都重复"顿笔→笔锋铺路"(加速下依然可辨);两根孤竹立在大片留白的深涧上,叶台是涧上唯一的路 | 快速横移,卷轴式 |
| 6.5–8.0s | 4x | 墨珠沿铺好的下行叶台落到一块皴笔大石上(石上存档灯点亮一点暖黄);随即踏上**全卷主笔**——一根被风压弯的大斜竹,沿弓起的竿身一路向右上奔跑,节痕从脚下连续掠过 | 沿斜竹大斜线移动,构图以斜竿贯穿对角 |
| 8.0–9.5s | 2x | 斜竹梢端,墨珠立在杈台上;前方又是一道更宽的留白深涧,远处卷尾的竹丛隐约可见;墨珠纵身跃出,空中冲刺点中最后一颗墨苞 | 短暂停顿(呼吸感),再跟随跃出 |
| 9.5–11.5s | **1x(第二记忆点)** | 末苞的**垂梢长下行**:笔锋连续画出四级逐级下落的枝叶台,一笔接一笔,墨珠踏着刚画完的台阶逐级落下,像踩着正在生长的楼梯;最后落回卷尾坡石 | 跟随下摇,笔锋走到哪镜头到哪 |
| 11.5–12.5s | 3x | 墨珠跑过卷尾竹丛,撞入终点的收笔圆环 | 横移收速 |
| 12.5–15.0s | 1x(渐慢) | **装裱终幕**:玩家冻结,镜头平滑拉远,整幅竹卷在画面中铺开——卷首到卷尾,玩家一路画出的所有竹枝竹叶清晰可见(没走的地方仍是断笔残卷);深褐装裱框从四边合拢、紧贴画心;右上浮现竖排题跋;最后一方**朱红印章**带回弹"砰"地盖下,微微定格,收黑 | 匀速 dolly out → 定格 |

## 4. 节奏与声音建议(若生成带音频)

- 0–12.5s:稀疏的古琴泛音 + 纸上运笔的沙沙声;每次"顿笔"配一声短促的墨点闷响。
- 12.5–15s:一记轻钟 + 印章落纸的厚实"砰",余韵收尾。
- 全片无人声、无鼓点;速度感全部交给画面变速。

## 5. 关卡事实依据(供生成时保持一致性)

- 关卡全长约 4750 世界像素,纵高 900;实际游玩 2~4 分钟。
- 全关共 **4 颗墨苞**,对应 4 次"冲刺点墨→笔锋铺路":跨第一涧(2 级台)、
  涧中双竿连段(2+2 级)、末苞垂梢(4 级长下行)。
- 路线节拍:卷首竹丛(杈梯)→ 第一涧 → 涧中孤丛连段 → 大石存档 → 风压斜竹长坡(主笔)→
  梢端杈台 → 末涧垂梢长下行 → 卷尾竹丛 → 收笔环 → 装裱终幕。
- 苞只认**冲刺命中**:普通触碰苞只会轻颤拒绝(若片中出现,可作 0.3s 的小幽默,非必需)。
- 画面密度曲线:密(卷首)—疏(涧)—中(孤丛)—密(主笔斜竹)—疏(末涧)—密(卷尾),
  与变速曲线同相:密处加速、记忆点处 1x。

## 6. 负面清单(生成时必须避免)

- 不要 3D 透视光影、不要体积光、不要景深虚化滥用;
- 不要彩色(除朱红印章与一点暖黄灯);
- 不要运动模糊表达速度(用墨尾长度);
- 不要 UI、血条、分数、按键提示;
- 不要把墨珠拟人化(无脸无四肢);
- 不要西式奇幻竹林(竹必须是写意笔触,不是写实植物)。
