# 玩家运动能力规范(Movement Spec)

> 本文是**地图设计的唯一运动学依据**。所有数值由 `tools/movement_metrics.py`
> 逐帧复刻 `scripts/src/50_simulation_update.lua` 的真实模拟得出(非连续物理近似)。
> 修改任何运动参数后,必须重新运行 `python tools/movement_metrics.py` 并更新本文表格。
>
> 单位:**世界像素 px**(与 `createBranch`/`createBranchPath` 坐标同单位)。
> 帧率:固定 60Hz(`FIXED_DT = 1/60`),表中"帧"均指固定步。

---

## 1. 帧模型(实现事实,改代码前必读)

每个固定步内,非冲刺状态的顺序为:

```
输入加速  vx ± = speed(1.6)
重力      vy += gravity
摩擦      vx *= friction
位移      x += vx ; y += vy
```

- **起跳**:`vy = jumpForce`(同帧仍会叠加一次重力)。**没有长按跳高**(不读跳跃键松开)。
- **冲刺(J)**:持续 **12 帧**,每帧 `vx,vy = dir * dashSpeed`(8 方向,斜向归一化),**冲刺中无重力**。
  - 结束帧:`vx *= 0.5`,**`vy` 原样保留** —— 这意味着:
    - 上冲刺结束后带着 `vy = -dashSpeed` 继续弹道上升(上冲刺实为"超级跳",见表);
    - 下冲刺结束后带着 `vy = +dashSpeed` 砸落。
- **冲刺刷新**(`canDash`):仅在 ①落地(枝面着地) ②蹬墙跳 ③冲刺命中目标 ④骑鹤/抓绳时恢复。**空中只有一次冲刺**。
- **蹬墙跳**:贴墙(按住朝墙方向 + 下落中)时跳:`vy = jumpForce*0.95`,`vx = 反墙向*11.5`(竹关:`*1.05 / 14`)。
- **贴墙下滑**:`vy` 上限 1.8 px/f(= 108 px/s;竹关 2.5)。
- **没有的东西**:无土狼时间(coyote time)、无跳跃缓冲(空中按跳直接作废)、无二段跳。
  设计地图时**不要**假设玩家有这些容错。
- 滑翔(仅枫关):贴近落叶时 `gravity=0.08`、`vy≤1.8`、空中加速 0.6/帧。
- 摔出世界:`y > worldH + 100` 直接重置玩家(无伤害,但会回出生点——**深坑即重开**)。

水平稳速公式:`v_run = speed × friction / (1 − friction)`。

\* 蹬墙跳远 = 蹬墙跳后**持续按住前进**回到起跳高度时的水平位移;松手值只有 60–71。

各列口径:

- **原地跳高**:无输入起跳的 apex 高度(可视为"能登上的最大台阶"的理论值)。
- **助跑跳远**:满稳速起跳 + 全程按住方向,回到**起跳同一高度**时的水平位移(平跳缺口口径)。
- **冲刺本体**:水平冲刺 12 帧位移(11×d + 0.5d);**余势**为冲刺后无输入滑行至 |vx|<0.3。
- **跳+冲刺最大平距**:满速助跑跳 → apex 处水平冲刺 → 继续按住方向,落回起跳高度的总位移。
  这是**单次空中能力的水平极限**。
- **上冲总高**:原地向上冲刺(12 帧)+ 结束后 `vy=-dashSpeed` 弹道余升的总高度。
- **跳+上冲总高**:起跳至 apex 后接上冲刺的总到达高度。这是**单次空中能力的垂直极限**。
- **45°上冲 dx/dy**:原地右上 45° 冲刺(含弹道余升结束时)的位移。

## 3. 地图设计规范(直接拿这些数排地形)

把"玩家必须做到"和"玩家极限"区分开,**必经路线一律打 8 折**:

### 3.1 必经路线上限(安全系数 0.8)

以 **standard** / **plum_swift** 两组为准(其余组按表内插):

| 地形需求 | standard 上限 | plum_swift(12/13关)上限 | 依据 |
|----------|---------------|--------------------------|------|
| 纯跳跃水平缺口 | **≤ 460** | ≤ 475 | 助跑跳远 × 0.8 |
| 纯跳跃上台阶 | **≤ 175** | ≤ 230 | 原地跳高 × 0.8 |
| 跳+冲刺水平缺口 | **≤ 630** | ≤ 670 | 最大平距 × 0.8 |
| 跳+上冲垂直通道 | **≤ 630** | ≤ 800 | 跳+上冲总高 × 0.8 |
| 单段冲刺穿越(窄缝/弹幕) | ≤ 175 | ≤ 195 | 冲刺本体 × 0.8 |
| 蹬墙跳横转移 | ≤ 450 | ≤ 470 | 蹬墙跳远 × 0.8 |
| 蹬墙跳上台阶 | ≤ 160 | ≤ 205 | 蹬墙跳高 × 0.8 |

### 3.2 挑战/隐藏路线上限(系数 0.95)

允许逼近极限,但**永远不要设计恰好 100% 极限值**的必经跳——离散帧物理 + 圆形碰撞会吃掉零点几帧的余量。

### 3.3 硬规则

1. **缺口宽 > 跳+冲刺最大平距 × 0.95 = 不可逾越**,可放心用作软墙。
2. **空中只有一次冲刺**:连续缺口之间必须给"落脚点"(枝面/平台/目标花苞)。
   - 例外:**冲刺命中目标会立刻刷新冲刺**——"花苞链"可以串出超长空中走廊,
     相邻花苞间距 ≤ 冲刺本体 × 0.8(standard ≈ 175,swift ≈ 195)。
   - 且普通关(非松/黄山的针刺敌、非竹/桃)命中花苞还会**强制弹跳 `vy = -18.5`**
     (弹起高度 ≈ 原地跳高的 1.3–1.5 倍:standard ≈ 329,swift ≈ 372),花苞本身就是一个"空中跳板"——
     花苞链允许"冲刺→弹起→再冲刺"的折线路径,垂直串联间距可放宽到 ≤ 300。
3. **垂直枝/字柱攀爬**依赖蹬墙跳循环:单柱可无限爬(贴墙下滑 108 px/s 给了充分反应时间);
   双柱夹缝左右蹬墙时,柱间距建议 120–360。
4. **下落即死区**(worldH+100 重置):任何引导玩家向下冲刺的设计,下方必须在
   滞空可达范围内有承接面;下冲刺落地冲击速度 = dashSpeed + 重力累积,视觉上要给预告。
5. **无土狼时间**:枝梢末端(半径 < 5 的发丝枝)作为起跳点时,有效起跳面比视觉短,
   要求玩家在末端起跳的设计需把缺口再收 10%。
6. 斜枝行走:站立判定要求接触法线 `ny < -0.4`(约 < 66° 的坡)。**更陡的枝段不能站立**,
   只能当墙蹬或冲刺穿越——画"近垂直枝"时要明确它的玩法角色。
7. 头顶障碍:`ny > 0.4` 的下表面会清零上升速度(撞头),跳跃通道净高 ≥ 玩家直径(22)+ 跳速余量,
   建议 ≥ 60。

### 3.4 节奏参考(时间手感)

- 一次完整跳跃滞空 ≈ 1 秒(59–71 帧);
- 冲刺 12 帧 = 0.2 秒;
- 跑过一屏(1280)≈ 2.2 秒(稳速 590 px/s);
- 玩家 0.27 秒(16 帧)即可从静止加速到 90% 稳速——短平台(≥ 100)就够重新起步。

## 4. 特殊关卡机制对运动的修正

| 关卡 | 机制 | 对设计的影响 |
|------|------|--------------|
| 1 竹 | 瀑布区上升气流(vy 最高 -14.2)+ 瀑布内冲刺加成/无限冲刺 | 瀑布是垂直电梯,内部不受表中垂直上限约束 |
| 2 松 | 溪流持续牵引(0.42/帧 along) | 顺流跳距 +~15%,逆流 -~15% |
| 3 枫 | 落叶滑翔(gravity 0.08)+ 枝条弹跳(extraJump) | 滑翔水平射程远超表值;弹枝可超 buff 跳高 |
| 5 桃 | 柳绳摆荡 + 浮瓣水面 | 摆荡出口速度由摆角决定,不在表内 |
| 6 阁 | 檐轨滑行、风铃弹射(jumpForce×1.05)、齿轮搭乘 | 弹射点 = 免费刷新冲刺的空中节点 |
| 7 黄山 | 骑鹤(随鹤位移)+ 云台 | 鹤是移动落脚点,下鹤自动冲刺 |
| 13 双清梅卷 | 无特殊机制,纯 plum_swift 参数 | 严格按表设计;长鞭梢下滑是地形坡度玩法 |
